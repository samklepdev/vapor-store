# Pinterest pin kit — VaporStudio42

Pinterest is a visual search engine and your #1 free discovery channel for printables.
Paste-ready pins below. You create the pins; this is the copy + image + link for each.

## One-time setup
1. **Business account** (free) — unlocks analytics + rich pins. Convert if personal.
2. **Create 2 boards:** "Vaporwave Battlestation Art" and "Psychedelic / Trippy Wall Art".
3. **Images: ready-made vertical pins.** Optimized 2:3 (1000×1500) pins for all 18
   products are in `pipeline/05-packaged/2026-10-21/pins/` as `pin-<slug>.png`
   (art + title + VaporStudio42 banner). Use these — vertical pins outperform square.
   Pin consistently (a few/week); fresh pins beat re-pins.

## Template for each new product you list
- **Image:** the piece's `-4x.png` (or framed mockup)

  `gumroad-battlestation.md` / `gumroad-psychedelia.md`, add 8–12 relevant hashtags
  (tag lists are in each doc's "Discovery & tags" section).

  rewards fresh pins and each is a new shot at search.
